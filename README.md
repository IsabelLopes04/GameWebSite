# Gamics 

Projeto de uma landing page com temática gamer, desenvolvido durante as aulas de desenvolvimento web, em conjunto com o professor.

A página apresenta uma interface voltada ao universo dos jogos, com seções de lançamentos, partidas, produtos e notícias.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Layout responsivo.
- Menu de navegação.
- Campo de busca visual.
- Botão para voltar ao topo.
- Seções temáticas sobre games.

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/IsabelLopes04/GameWebSite.git
   ```

2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
